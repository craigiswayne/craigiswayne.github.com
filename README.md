# My Portfolio

### ATS Checks
* < 2MB
* Experience Section (titles should be: "Work History" or "Professional Experience")
* Education Section
* Summary Section
* PDF
* Include LinkedIn Link
* Email Address
* Phone Number international format
* No Spelling Mistakes
* Dates properly formatted

* No Background Colors
* Reverse Chronological Order
* One Column Layout

* Common Headings:
  * Contact Information
  * Experience
  * Education
  * Certificates
  * Skills
  * Languages
  * Summary
* Clear Typography Hierarchy

* Friendly Fonts
  * Any Legible font

* Content to Include:
  * Contact Details
  * Location
  * Experience
  * Education
  * Certificates
  * Skills
  * Languages

* Content to exclude:
  * Profile Image
  * Birthday
  * Marital Status
  * Gender
  * source: https://www.wozber.com/en-gb/cv-templates/ats-friendly
* Reasons why Resume parsing fails (https://support.greenhouse.io/hc/en-us/articles/200989175-Unsuccessful-resume-parse)
* Don't shorten titles like "Snr. Frontend Developer" instead use "Senior Frontend Developer"
